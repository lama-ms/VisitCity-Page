# Visit Riyadh – City Guide

A simple city guide landing page built using HTML and CSS. The webpage introduces Riyadh and highlights popular attractions through a visually styled layout.

## Features

- **Hero Section:** A welcome banner featuring a background image of Riyadh.
- **Featured Attractions:** Three destination cards highlighting Diriyah, the National Museum of Saudi Arabia, and Boulevard City.
- **Image Styling:** Circular attraction images with CSS styling.
- **Guide Section:** A personalized guide card with an avatar and introduction.
- **Page Layout:** Uses CSS Flexbox to arrange attraction cards and guide content.
- **Custom Design:** Uses background images, contrasting colors, typography, and text shadows.

## Technologies Used

- HTML5
- CSS3
